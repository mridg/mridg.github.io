Built a Python-based emulation framework for a custom SmartNIC so software development
and validation could start before silicon exists. Implemented Ethernet and RDMA
communication layers to bridge host software with accelerator hardware, enabling
hardware-software co-design and system-level testing, and designed workload-driven
benchmarks using AICB to characterize packet processing behavior and RDMA offload
performance.

Purdue VIP SoCET — Datacenter Network Accelerator.
